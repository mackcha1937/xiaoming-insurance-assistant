# 产品 36743 正式资料接收目录

请只放置经过确认、允许用于内部 POC 的正式产品资料，不要放 API Key、客户身份信息、
健康资料或真实会话。

当前批次使用 `raw/01-...` 至 `raw/21-...` 的固定文件名、类型和 SHA-256，详见
`docs/acceptance/phase-02-source-intake.md`。导入器会在解析前逐文件校验哈希，文件缺失、
被替换、为符号链接或越出本目录时立即停止。

`资料清单.md`：复制 `资料清单.md.example` 后填写来源、版本、生效状态和 POC 使用确认。
实际清单与原始资料一样只保存在本机，不提交到 Git。

原始文件不得直接提交到 Git。常规启动默认不导入；只有显式启用
`XIAOMING_KNOWLEDGE_IMPORT_ENABLED` 并指定本目录后，才会生成页码映射、语义片段、结构化
规则和发布快照。
