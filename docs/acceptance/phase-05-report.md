## 2. 验收中发现并修复的问题

1. Vue 响应式 Proxy 不能直接使用 `structuredClone` 写入 IndexedDB，真实浏览器会抛出 `DataCloneError`；改为只克隆可持久化 JSON 快照，并增加保存回滚测试。
2. 首版写入了 `lastConversationId` 偏好但初始化没有读取，导致恢复客户 A 后刷新又回到客户 B；现已读取并显式更新当前客户偏好，自动化和真实刷新复验均通过。
3. 历史低频菜单的两个操作按钮曾定位重叠；改为独立弹出菜单容器。
4. 新建、历史、删除、清空和重新生成弹层首版只有 Esc，没有完整 Tab 焦点循环与焦点归还；现已补齐焦点锁定、Esc 取消、背景隔离和触发点归还。
5. 本机导出首版未包含预留的 healthFacts store；现已纳入完整导出范围，清空仍覆盖全部五个 store。
6. 迁移失败提示首版只说明旧数据保留；现明确给出重试、导出或清空入口，且不静默删除旧库。
7. 新能力数量变化导致旧契约断言不一致；已同步生成契约与回归断言。
