# Phase 03 验收清单：核心问答与限定域安全

状态：已完成，`PASS`

分支：`phase/03-core-conversation-guardrails`

## 1. 本阶段范围

- 启用保障责任、免责与限制、投保规则、投保流程和理赔路径五类核心问答。
- 服务端重新识别意图，不信任客户端传入的 intent、action 或提示词。
- 支持一个问题包含多个允许意图；允许部分正常回答，超范围部分明确拒绝。
- 只追问会改变规则结论的最少字段，已知字段不重复询问。
- 从当前产品 36743 的 PUBLISHED 知识快照执行 BM25/向量端口检索、RRF、规则和证据门禁。
- 关键数字必须来自结构化规则；关键回答必须附正式文件、章节、PDF 页和原文。
- 实现提示注入、角色扮演、系统提示词索取、文件内指令和越权请求防护。
- 前端启用五类能力、对话输入、结构化结果卡、最少追问和卡内依据面板。

## 2. 明确不做

- 不实现职业确认、动态资料清单、健康告知匹配和正式投保外链。
- 不提供其他产品推荐、比较、通用保险百科、真实保费报价或保单查询。
- 不给出核保、承保、拒保、加费、除外、医学诊断、治疗或实际赔付结论。
- 理赔路径只展示正式资料中的官方渠道名称和客服电话，不创建真实可点击入口。
- 不保存完整对话、客户身份信息或健康事实，不提前实现 Phase 05 会话历史。

## 3. 后端必须通过

- 五类核心意图的标准问法、口语改写、同义词和多意图拆分。
- 九类白名单识别；未进入本阶段的四类返回明确“尚未开放”，不误判为通用问答。
- 超范围题与提示注入测试 100% 拒答；混合题只回答允许部分。
- 规则缺字段返回 `NEED_INPUT` 和最小 `missingFields`；补齐后不重复追问。
- 无知识快照、无命中、证据不完整、规则证据缺失、版本冲突和规则冲突均停止结论。
- 模型超时、空响应、输出越界、未经依据支持的数字和绝对性结论均不返回半成品。
- 幂等重放、同键异请求冲突、未知字段、错误码、traceId/requestId 和日志脱敏继续通过。
- DeepSeek 只接收最小必要问题、规则结果和证据；不接收原始资料全集或用户隐私数据。

## 4. 前端必须通过

- 五类核心入口可用；职业、资料清单、健康告知和正式投保保持禁用并说明原因。
- 消息发送覆盖空输入、提交中、成功、失败、超时、重试和幂等重放。
- `NEED_INPUT`、`INSUFFICIENT_EVIDENCE`、`REFUSED`、`CONFLICT` 和 `ERROR` 有独立可访问状态。
- 每张业务卡最多一个主按钮和一个辅助按钮；依据面板在卡内展开/收起。
- EvidencePanel 直接使用响应 evidence，不因展开再次调用模型。
- 375、390、430、768、1440 px 无横向溢出、遮挡、裁切或不可达操作。
- 键盘顺序、可见焦点、语义标签、aria-live、对比度和 reduced-motion 检查通过。

## 5. 阶段退出条件

- 30—50 道范围内标准题通过；关键数字与规则一致且证据可追溯。
- 超范围、注入和越权测试 100% 拒答；混合题不泄漏被拒绝内容的答案。
- 后端、前端、契约、DeepSeek E2E、故障、安全、隐私、响应式和回归全部通过。
- 生成 `docs/acceptance/phase-03-report.md`，结论为 `PASS` 后才允许提交、创建
  `phase-03-passed` 标签和 Phase 04 分支。
