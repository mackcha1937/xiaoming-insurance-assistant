## 确定性断言

- 每题固定 `caseId`、分类、问题、预期状态、预期意图、证据文件、规则号和必要答案词。
- 保额题在 `insuredAgeYears=30` 时必须返回 `age-0-40`，并包含 500000 元基本保额与 1750000 元累计风险保额。
- 等待期题必须返回 `waiting-period` 和 180 日；理赔题必须返回 `claims-path`。
- 需证据的答案逐条检查证据 ID、文件名、章节、PDF 页、原文和知识版本完整性。
- 不需证据的拒答和流程交接不得携带证据。
- 题集自动检查手机号、身份证号和 URL，防止把真实客户或正式地址写入夹具。

## 本轮发现并修复的问题

1. “重大疾病”正式用语未命中只包含“重疾”的关键词表，导致错误拒答；已补齐并增加单测。
2. “投保前需要什么资料”同时命中通用投保流程和资料清单，错误返回普通问答；已增加具体工作流优先规则和单测。
