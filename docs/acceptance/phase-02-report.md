# Phase 02 验收报告：知识版本、规则与证据底座

## 1. 阶段范围结论

本阶段完成产品与知识版本、资料状态、文件哈希、页码映射、语义切分、BM25/向量检索端口、
RRF、安全降级、结构化规则条件树、EvidenceService 和证据门禁。产品固定为 `36743`，知识
版本为 `knowledge-36743-2026-08-27`，规则版本为 `V1-202508+TBXZSV-202604`，职业模板为
`1963059331068178434`。

产品资料自动导入默认关闭。只有显式启用并指定本地忽略目录时，导入器才逐文件校验固定
SHA-256、解析、提交 REVIEW、执行发布校验并原子切换 PUBLISHED 版本；普通启动不会加载
UAT 原始文件，也不会调用 DeepSeek。

发布时快照激活与版本切换处于同一同步临界区：快照激活失败会中止切换，旧版本继续保持
PUBLISHED，候选版本保持 REVIEW。应用固定为 Servlet/H5 模式，知识导入启动任务优先于
其他 ApplicationRunner，避免交互 Shell 阻塞导入。

本阶段没有实现 Phase 03 的真实问答、意图编排和依据面板，也没有提前实现职业确认、会话
历史、客户资料清单、健康告知匹配或正式投保外链。

## 6. 非阻塞限制

- 健康告知是 UAT 页面预览文本且无独立版本号。用户已确认其可用于内部 POC，但后续界面
  必须持续展示“仅供预览，非投保流程”，不得生成核保或承保结论。
- 费率与现金价值表已完整扫描和抽样，但 POC 明确不做真实报价、现金价值或退保金额计算，
  因此这些表只作为版本化来源留存，不作为当前业务结论引擎。
- Phase 02 只建立向量检索端口和故障策略；实际向量服务与真实问答属于后续显式范围，
  本阶段不消耗 DeepSeek API。
